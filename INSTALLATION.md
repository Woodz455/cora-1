# Installer Clora sur Windows

Cette page s'adresse à la personne qui va utiliser Clora. Aucune connaissance
technique n'est nécessaire : il y a trois étapes, et la deuxième demande un
petit détour que Windows impose à tous les logiciels qui ne viennent pas du
Microsoft Store.

Comptez deux minutes.

## 1. Télécharger le fichier

Rendez-vous sur la page des versions du projet et téléchargez le fichier dont
le nom ressemble à :

```
Clora-Installateur-1.2.0.exe
```

Il fait environ 100 Mo. Votre navigateur le déposera dans le dossier
**Téléchargements**.

Il se peut que le navigateur affiche un avertissement du genre « ce fichier
n'est pas téléchargé couramment ». Choisissez **Conserver**.

## 2. Lancer l'installation

Double-cliquez sur le fichier téléchargé.

**Windows va afficher une fenêtre bleue** intitulée « Windows a protégé votre
ordinateur ». C'est normal, et cela n'indique pas que le fichier est
dangereux : Windows réagit ainsi devant tout logiciel qui n'a pas été
enregistré auprès de Microsoft, une démarche payante que Clora n'a pas
effectuée.

Pour continuer :

1. cliquez sur **Informations complémentaires** (le lien discret sous le texte) ;
2. cliquez sur le bouton **Exécuter quand même** qui apparaît alors.

L'installation se déroule ensuite toute seule, sans aucune question. Une barre
de progression s'affiche quelques secondes, puis Clora s'ouvre.

> Aucune autorisation d'administrateur ne vous sera demandée : Clora s'installe
> dans votre compte utilisateur uniquement.

## 3. Créer votre compte

Au tout premier démarrage, Clora demande de choisir un nom d'utilisateur et un
mot de passe. Ce compte protège vos données comptables ; il reste sur votre
ordinateur et n'est envoyé nulle part.

Notez le mot de passe quelque part : il n'y a pas de procédure de
récupération.

## Les fois suivantes

Une icône **Clora** a été ajoutée sur votre bureau et dans le menu Démarrer.
Un clic dessus ouvre l'application.

## Questions courantes

**Où sont enregistrées mes factures ?**
Dans votre dossier personnel, sur cet ordinateur. Rien n'est envoyé sur
Internet. Pensez à faire des sauvegardes.

**Puis-je installer Clora sur un deuxième ordinateur ?**
Oui, mais les deux ne partageront pas les mêmes données : chaque installation
tient sa propre comptabilité.

**Comment désinstaller ?**
Par *Paramètres → Applications → Clora → Désinstaller*. **Vos données ne sont
pas effacées** : elles restent en place, et une réinstallation les retrouve.

**Windows affiche toujours l'avertissement bleu à chaque mise à jour.**
Oui, tant que le logiciel n'est pas enregistré auprès de Microsoft. La marche à
suivre est la même que ci-dessus.
