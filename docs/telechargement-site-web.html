Télécharger pour Windows

Un seul fichier. Double-cliquez : Clora s'installe sans poser de question et place une icône sur votre bureau. Aucun mot de passe administrateur n'est demandé.

Windows affichera un avertissement bleu. C'est attendu. Il apparaît pour tout logiciel dont l'éditeur n'a pas acheté de certificat de signature auprès de Microsoft. Cliquez sur Informations complémentaires, puis sur Exécuter quand même.

Vos factures, vos clients et vos écritures restent sur votre ordinateur, dans un fichier que vous pouvez copier ou emporter. Clora ne les envoie nulle part. Sa seule connexion sortante sert à vérifier s'il existe une version plus récente, et elle se coupe depuis les Paramètres.
