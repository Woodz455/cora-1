Que se passe-t-il si je change d'ordinateur ?
Votre licence vous suit. Copiez le dossier de données de Clora (%APPDATA%\Clora), réinstallez, saisissez la même clé. Seul le mot de passe de votre serveur de courriel est à ressaisir : il est chiffré par le coffre-fort de Windows, donc lié à votre ancien poste.
